# Mohanad Abubaker — Portfolio

Personal portfolio of Mohanad Abubaker: Grade 12 STEM student, FIRST Global gold medalist (Team Sudan) and ICSC Ambassador.

Live site: https://mohanadportfolio.lovable.app

## What's inside

- Home page with hero, about, skills, projects, achievements, certificates and contact form
- Project pages: Agri-Shield 4.0, AFAQ, NOVA City, Team Sudan Robot, Smart Greenhouse
- Interactive 3D models (.glb) of the Agri-Shield prototype and the Team Sudan robot
- Contact form backed by a validated, rate-limited backend function

## Built with

- React 18, TypeScript, Vite
- Tailwind CSS
- three.js / React Three Fiber (3D models)
- Lovable Cloud (database, storage and backend functions)

## Run locally

```sh
npm install
npm run dev
```
